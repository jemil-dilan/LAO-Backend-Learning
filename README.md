# Exercise No 4

### GESTION D'UTILISATEUR


* Le projet contient les différent operation CRUD neccessaire pour géré des utilisateur en terme
  générale, sans implémenté des fonctionalité spécific comme des role, encryption des mot de passe etc.

* Le projet utilise docker compose avec postgres pour la base de donnée que vous pourriez découvrir dans le fichier compose.yaml
* Le projet utilise liquibase pour la gestion du schema de la base de donnée
